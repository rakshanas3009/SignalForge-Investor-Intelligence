4. REAL RAG IMPLEMENTATION
==========================

Implement a working retrieval-augmented generation component.

Create a small document corpus for the demo containing financial/regulatory documents.

The system must:

1. Store/index documents.
2. Split documents into searchable chunks.
3. Accept a natural-language query.
4. Retrieve the most relevant chunks.
5. Send retrieved context to the Fundamental Agent.
6. Generate the fundamental analysis using ONLY the retrieved context for document-specific claims.
7. Return source metadata.

Each retrieved source should contain:

* document name
* section/page if available
* retrieved excerpt
* relevance score

Display these sources directly underneath the Fundamental Agent result.

Example UI:

EVIDENCE USED

Financial Filing
Page/Section: ...
Relevance: 91%
Excerpt: ...

USED BY FUNDAMENTAL AGENT

Never display an invented citation.
